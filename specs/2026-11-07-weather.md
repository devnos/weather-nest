# Weather Nest
Простой русскоязычный прогноз для любого города из Open-Meteo
Аудитория: пользователь телефона или компьютера, которому нужна погода перед выходом
Дизайн: спокойный, современный, светлый, без декоративной навигации
Критерии: поиск с вариантами городов, текущая погода, ближайшие 12 часов, 7 дней, ошибки и загрузка, мобильная версия, GitHub Pages /weather-nest/
Данные: https://open-meteo.com/en/docs и https://open-meteo.com/en/docs/geocoding-api
Бесплатное некоммерческое использование без ключей
Решение: нативные HTML/CSS/JS; React избыточен, сервер не нужен, OpenWeather потребовал бы ключ
