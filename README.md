# Погода рядом
Статическое приложение без зависимостей и ключей API

Запуск: откройте index.html или выполните `python -m http.server 8765`
Проверка: `node test.cjs`

Данные: [Open-Meteo](https://open-meteo.com/), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
Бесплатный API предназначен для некоммерческого использования
Название города передаётся Open-Meteo для поиска; последний выбранный город сохраняется только в localStorage браузера

Публикация: GitHub Pages, ветка main, папка / (адрес проекта /weather-nest/)
Все ресурсы используют относительные пути

Темы: системная по умолчанию, ручной выбор сохраняется в браузере
Иконки: Lucide SVG, ISC license в LUCIDE-LICENSE.txt
Источник иконок: https://github.com/lucide-icons/lucide/tree/53fab88ff9d1b48f4704b5b5b560d6b4d560bf4c/icons
